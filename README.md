# SmartOrder: Haushaltsverwaltung und Nachbestellung

Ein THI Projekt des CND Moduls im Master Studiengang Cloud Applications and Security Engineering.
Es besteht aus diversen Microservices, die zusammen ein cloud native System bilden und entsprechend der hexagonalen Architektur aufgebaut sind.

Es kann sowohl lokal, per Docker Compose, als auch in einem Kubernetes-Cluster mit Helm deployed werden.
