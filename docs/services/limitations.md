# Limitationen

Da es sich bei diesem Projekt um ein Studierendenprojekt handelt, gibt es einige Limitationen, die keine vollständige Funktionalität für den produktiven Einsatz garantieren. Diese Limitationen sind:

- **Preise**: Es werden keine realen Preise verwendet, sondern fiktive Werte, um die Funktionalität zu demonstrieren. Dazu müssen spezielle im Frontend bereitgestellte Mock Links verwendet werden.
- **Bestellungen**: Es werden keine echten Bestellungen durchgeführt, sondern nur simuliert. Eine reale Implementierung des Bestellvorgangs erfordert die zusätzliche implementierung von Authentisierungsmethoden und Parametern, die von der verwendeten drittanbieter-API (z.B. Amazon API) vorgegeben werden. 
- **Authentifizierung**: Es werden keine Regeln für besonders sichere Passwörter oder eine Zwei-Faktor-Authentifizierung verwendet. Die Länge und Sicherheit des Passworts wird dem Nutzer überlassen.
- **Objekte**: Es können keine eigenen Kategorien erstellt werden, sondern nur die vorgegebenen Kategorien verwendet werden.
- **Bestellanzahl**: Die Anzahl der zu bestellenden Objekte kann in der Bestellliste nicht angepasst werden und wird bei einem Bestellvorgang nicht mit der Verfügbaren Anzahl abgeglichen.
